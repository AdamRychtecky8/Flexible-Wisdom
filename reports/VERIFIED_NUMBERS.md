## 5. Weighted Linear Combination (WLC) -- Removed

WLC was removed from the active pipeline (`Main-Analysis.ipynb`) and `outputs/wlc-cv-results.csv` deleted. The implementation applied a log-odds transform to binary model decisions (0/1), collapsing all inputs to +/-13.8 before weighting, which produced accuracy below majority voting in every condition (human: 0.572-0.658; LLM: 0.595-0.650 vs. MV human: 0.637-0.784, MV LLM: 0.835-0.884). The bug is in the method design, not the arithmetic. Git history preserves the removed code.
